دکمه شناور تماس با کانال‌های ارتباطی دلخواه (تماس، واتساپ، تلگرام، اینستاگرام و ...) برای همه صفحات یا صفحات انتخابی.

== Description ==

طراحی شده توسط مهدی حبیبی | طاووس وب — https://tavoosweb.ir/

* نمایش در همه صفحات، فقط صفحات انتخاب‌شده یا همه به جز صفحات انتخاب‌شده
* ۸ موقعیت آماده و موقعیت دلخواه درصدی (W/H)
* آیکون دکمه قابل تغییر (آیکون آماده، SVG دلخواه یا تصویر)
* رنگ ثابت یا گرادیان برای دکمه و رنگ‌بندی منو
* کانال‌های ارتباطی نامحدود با امکان افزودن، حذف و جابجایی
* تنظیمات جداگانه اندازه و فاصله برای موبایل

آموزش تصویری کامل در فایل README.md و پوشه docs/screenshots.

== Installation ==

1. پوشه افزونه را در wp-content/plugins بارگذاری کنید.
2. افزونه را از منوی افزونه‌ها فعال کنید.
3. از منوی «دکمه تماس» در پیشخوان تنظیمات را انجام دهید.
